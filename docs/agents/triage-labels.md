# Triage labels

Use these labels on Beads issues when an engineering skill refers to
a canonical triage role.

| Canonical role | Beads label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | The issue needs more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is specified and ready for an unattended agent. |
| `ready-for-human` | `ready-for-human` | The issue requires human implementation. |
| `wontfix` | `wontfix` | The issue will not be implemented. |

Apply the corresponding Beads label when a skill names one of these
roles. Labels do not replace Beads status or dependency tracking.
