# Tracing a piece with its QR code

Every vCraft product has an 8-character trace code and a QR code, usually printed on the base of the piece. Scanning the QR with a phone camera opens the product's trace page.

The trace page tells the piece's journey: the household that made it, the people at each stage (shaping, drying, painting, glazing, firing) and the production journal with photos. The journal is hash-chained, so it cannot be changed quietly.

If the product is no longer on display, the page says so instead of showing an error. You can also type the trace code into the search box.
