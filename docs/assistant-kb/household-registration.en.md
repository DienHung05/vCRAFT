# Registering as an artisan household

Pottery households in Bát Tràng register through "Register as an artisan household": create an account, fill in the household details (name, story, the representative's citizen ID number), add a workshop and pin it on the map, then upload verification documents.

The village board reviews the application. Once approved, the household's page goes public and the household can use Studio to list products, keep a production journal and receive quote invitations.

The citizen ID number is encrypted and only the board can see it when reviewing. A household that is pending, rejected or suspended only sees its application status page.
