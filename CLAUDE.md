## Commit attribution

Commits and pull requests are authored by the repository owner. Never add `Co-Authored-By: Claude`, `Claude-Session:` or any other Claude attribution line to commit messages, and no "Generated with Claude Code" footer to PR descriptions: GitHub then shows Claude's avatar next to the owner's. Commit with the owner's git identity, never `Claude <noreply@anthropic.com>`.
